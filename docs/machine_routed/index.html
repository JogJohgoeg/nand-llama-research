  • 上一版的违例几乎全在宏上方的 met5：主体单元被摆进宏与宏之间的缝里，它们的连线只能从宏顶上绕。第二版给两侧宏带加了放置禁区，并降低放置密度，让主体在中间铺开；第三版沿用第二版的摆放，只把全局布线预留的余量从 30% 调到 20%，剩下的 10 处随之消失。
  • 网表没变：三版综合结果相同，只是摆放和走线不同。还原后的门级电路逐字节一致，所以上面的功能回放结论对三版都成立。
  • 整机网表来自 H 的 R135：整机主体 189,989 NAND / 80,283 LATCH；共享权重表（31.7 万门）按地址高 7 位切成 128 块，120 块非零，各做成独立的宏，用 OR 链串起来。H 已对全部 32,768 个地址证明切块后与原表逐字相同。
  • 工具：LibreLane 3.0.14 / OpenROAD / KLayout，在自有机器上运行。
