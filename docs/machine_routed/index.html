这是怎么做出来的

  • 整机网表来自 H 的 R135：整机主体 189,989 NAND / 80,283 LATCH，共享权重表移到外面。
  • 共享权重表（31.7 万门）平铺布不通，按地址高 7 位切成 128 块，其中 120 块非零，每块做成独立的宏；各块用 OR 链串起来，进中间的线只有 1,280 根。H 已对全部 32,768 个地址证明分块后与原表逐字相同。
  • 层级 RTL 已在 Verilator 上跑通 3 个 C 用例（下一个 token 分别为 32、5、128）；这份布线后网表的门级回放由 H 在跑。
  • 工具：LibreLane 3.0.14 / OpenROAD，在自有机器上运行。
